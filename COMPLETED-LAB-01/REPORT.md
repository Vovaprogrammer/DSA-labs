## 2. Реализации и аналитическая оценка сложности

### 2.1 Сумма элементов массива — `array_sum`

```python
def array_sum(a: list[int]) -> int:
    total = 0
    for num in a:
        total += num
    return total
```

**Оценка: O(n).** Один проход по массиву, на каждом элементе — константная
работа (одно сложение). Лучший, средний и худший случаи совпадают: нет ранних
выходов и ветвлений, зависящих от данных.

### 2.2 Поиск максимума — `array_max`

```python
def array_max(a: list[int]) -> int:
    max_val = a[0]
    for i in range(1, len(a)):
        if a[i] > max_val:
            max_val = a[i]
    return max_val
```

**Оценка: O(n).** Один проход, на каждом шаге — одно сравнение и, в худшем
случае, одно присваивание. Асимптотика не зависит от порядка данных
(random / sorted / reverse-sorted / constant дают одинаковый порядок роста,
хотя число обновлений `max_val` отличается).

### 2.3 Подсчёт пар равных элементов — `count_equal_pairs`

```python
def count_equal_pairs(a: list[int]) -> int:
    count = 0
    n = len(a)
    for i in range(n):
        for j in range(i + 1, n):
            if a[i] == a[j]:
                count += 1
    return count
```

**Оценка: O(n²).** Вложенный цикл: внешний проходит n раз, внутренний —
в среднем n/2 раз. Суммарное число итераций — n(n-1)/2, то есть Θ(n²) в
любом случае (не только в худшем): цикл всегда обходит все пары независимо
от содержимого массива.

### 2.4 Бинарное возведение в степень — `binary_pow`

```python
def binary_pow(x: int, n: int, mod: int | None = None) -> int:
    result = 1
    if mod is not None:
        x %= mod
    while n > 0:
        if n % 2 == 1:
            result = (result * x) % mod if mod is not None else result * x
        x = (x ** 2) % mod if mod is not None else x ** 2
        n //= 2
    return result
```

**Оценка: O(log n).** Показатель степени n раскладывается по битам; на
каждой итерации цикла `n` делится на 2, поэтому число итераций равно числу
битов в n, то есть ⌊log₂ n⌋ + 1. Внутри итерации — константное число
операций (максимум два умножения по модулю).

## 3. Методика замеров

В соответствии с `docs/reproducibility.md`:

- таймер — `time.perf_counter()`;
- первый запуск каждой реализации (прогрев) не учитывается;
- на каждый размер n — не менее 5 повторов, фиксируется **медиана**;
- ряд размеров — геометрический, 10³ … 10⁵ (данные варианта);
- условия: `<CPU, отсутствие фоновой нагрузки, от сети/без батареи и т.д.>`.

Для `array_sum`, `array_max`, `count_equal_pairs` — график в осях **log-log**
(степенная зависимость на таком графике — прямая, наклон = показатель
степени). Для `binary_pow` — график **t(log₂ n)** в линейных осях, а не
log-log.

**Почему log-log неинформативен для `binary_pow`.** На log-log графике
логарифмическая зависимость выглядит почти горизонтальной кривой без
выраженного наклона — по такому графику нельзя визуально подтвердить
O(log n). Чтобы увидеть прямую линию, подтверждающую логарифмический
рост, время нужно откладывать как функцию от **log₂ n** в линейных осях —
тогда O(log n) даёт прямую с наклоном, пропорциональным константе
алгоритма.

## 6. Верификация решений

По методике `docs/ai-verification.md`.

### 6.1 Инварианты

| Алгоритм | Инвариант |
|---|---|
| array_sum | результат равен сумме всех элементов входа; не зависит от порядка суммирования (коммутативность сложения) |
| array_max | результат — элемент, присутствующий во входном массиве; ни один элемент массива не превышает результат |
| count_equal_pairs | результат ≥ 0; результат = 0 тогда и только тогда, когда все элементы попарно различны |
| binary_pow | результат при `mod=None` равен `x**n`; при заданном `mod` — равен `pow(x, n, mod)` |

### 6.2 Репрезентативные тесты

- пустой массив (`array_sum([]) == 0`; для `array_max` — не определён/поднимает исключение согласно контракту, что зафиксировано отдельно, так как условие гарантирует непустой массив);
- массив из одного элемента;
- массив, где все элементы равны (граничный случай для `count_equal_pairs` — максимальное число пар);
- `binary_pow` — `n = 0` (результат 1), `n = 1` (результат x), большие n с `mod`.

### 6.3 Сравнение с эталоном

```python
import random

for _ in range(500):
    arr = [random.randint(-100, 100) for _ in range(random.randint(1, 50))]
    assert array_sum(arr) == sum(arr)
    assert array_max(arr) == max(arr)

for _ in range(500):
    x, n, mod = random.randint(1, 50), random.randint(0, 30), random.randint(2, 10**6)
    assert binary_pow(x, n, mod) == pow(x, n, mod)
```
